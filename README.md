# Trabby (트라비)

걸음 수로 지하철 노선 위를 걸어가며 노선을 도감처럼 수집하는 앱 (React Native + Expo).

## 실행 (Windows + Android Studio 에뮬레이터)
1. Android Studio에서 에뮬레이터를 먼저 켭니다.
2. `run.bat` 더블클릭 → 터미널에서 `a` 키.
3. 에뮬레이터에는 걸음 센서가 없어요. 홈 화면 하단 `+300 걸음 (DEV)` 버튼으로 테스트하세요.

- **노선 데이터 갱신/보완 방법** → [docs/데이터-갱신.md](docs/데이터-갱신.md)

## 핵심 규칙
- 걸음은 **한 번에 한 노선(코스)** 에만 쌓입니다. 다른 노선으로 바꾸면 이전 진행도는 저장된 채 "일시정지".
- 노선에 역이 늘어나도 **완주 기록은 유지**되고, 새 구간만 이어서 걸을 수 있어요.
- **보상**: 노선(본선)을 완주하면 **그 노선 색 테마**, 갈래가 있는 노선의 **추가 코스**(1호선 코스들, 2호선·5호선 지선)를 완주하면 **캐릭터**. 뱃지는 코스마다, 코스가 여러 개인 노선은 전 코스 완주 시 "전 코스" 뱃지.
- 걸음 → 거리는 고정 보폭 60cm (`src/lib/progress.ts`).
